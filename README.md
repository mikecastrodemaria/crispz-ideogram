# crispz-ideogram

Local Ideogram 4.0 studio of the crispz family: text-accurate image generation
(posters, logos, packaging, typography), structured JSON captions, emulated
img2img / inpaint, and optional Ideogram 4.5 cloud tools (edit, background, vector).

**Status: specification only.** No code yet. The plan, the base fork choice
(crispz-flux3) and the work lots are in [CLAUDE.md](CLAUDE.md).

**Licence warning.** Ideogram 4.0 open weights are under the Ideogram 4
Non-Commercial licence: personal and research use only, commercial use of the
self-hosted weights needs a separate licence from Ideogram.
